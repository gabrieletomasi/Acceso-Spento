# Acceso-Spento
## Breve descrizione del progetto
Questo progetto realizzato modello ML, realizzato con edge impulse, caricato sulla scheda Arduino Nano 33 BLE sense Rev2, per il riconoscimento delle due parole "acceso" e "spento". L'idea è quella di utilizzarle per comandare l'accensione di luci con comando vocale.
I dati sono stati acquisiti con Edge Impulse, associando la scheda Arduino ed utilizzando il sensore MP34DT06JTR con la libreria PDM.
